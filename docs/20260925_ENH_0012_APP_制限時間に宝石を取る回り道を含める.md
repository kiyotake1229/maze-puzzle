# 制限時間に、宝石を取る回り道を含める

- 管理番号: #0012
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0003（`bestRoute` を追加）、#0002（宝石が必ず取れるようにした）

## 概要

タイムアタックとスーパーハードの制限時間は、宝石を取らずにゴールする道の長さで決めていた。そのため、宝石を全部取る（★3 を狙う）と時間が足りなくなりやすかった。制限時間の基準を「鍵と宝石を全部取ってゴールする最短ルート」に変え、★3 を時間内に狙えるようにした。

## 対象ファイル

- `index.html` … `newLevel`（制限時間の計算）

## 変更内容

- 基準にするマス数を、「スタート → 鍵 → ゴール」の距離（滑る動きは考えない）から、`bestRoute`（#0003）で求める「滑る動きで、鍵と宝石を全部取ってゴールする最短マス数」に変えた
- 1マスあたりの時間はこれまでと同じ（タイムアタック 0.9 秒、スーパーハード 0.6 秒）。最低時間（8 秒 / 6 秒）も同じ

### 制限時間の変化（各 80〜300 面の平均）

| モード | 迷路 | これまで | これから | 倍率 |
|---|---|---|---|---|
| タイムアタック | 8×8（Level 1） | 28.1 秒 | 42.7 秒 | 1.67 |
| タイムアタック | 12×12（Level 3） | 79.3 秒 | 107.9 秒 | 1.46 |
| タイムアタック | 16×16（Level 5） | 133.0 秒 | 177.9 秒 | 1.44 |
| タイムアタック | 26×26（Level 10） | 306.6 秒 | 419.0 秒 | 1.48 |
| スーパーハード | 12×12（Level 1） | 51.8 秒 | 73.0 秒 | 1.56 |
| スーパーハード | 20×20（Level 5） | 128.0 秒 | 176.9 秒 | 1.47 |
| スーパーハード | 30×30（Level 10） | 256.9 秒 | 343.2 秒 | 1.44 |

### 遊び方への影響と調整の余地

- 宝石を全部取る最短ルートを、これまでと同じペース（1マス 0.9 秒 / 0.6 秒）で進めば間に合う
- 宝石を取らずにゴールだけを目指す場合は、これまでより時間に余裕ができる（平均 1.4〜1.7 倍）
- 簡単すぎると感じたら、`newLevel` の `factor`（0.9 / 0.6）を下げれば全体を厳しくできる

## 確認結果

- タイムアタック（Level 1・2・5）とスーパーハード（Level 1・3）で各 100 面作り、制限時間が「宝石を全部取る最短マス数 × 1マスの時間」（最低時間あり）になっていることを確かめた。500 面すべて一致
- 画面でタイムアタックに切り替え、「Left」に新しい制限時間が表示されることを確かめた
