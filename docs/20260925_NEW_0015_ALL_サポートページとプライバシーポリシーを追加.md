# サポートページとプライバシーポリシーを追加

- 管理番号: #0015
- 種類: NEW（新機能）
- 対象: プロジェクト全体（ALL）
- 作成日: 2026-09-25
- 関連: #0016（iOS アプリ化。App Store 申請でこのページの URL を使う）

## 概要

App Store への申請には、サポート URL（問い合わせ先が載ったページ）とプライバシーポリシーの URL が必要になる。また、アプリの中からもプライバシーポリシーを開ける必要がある（App Store 審査ガイドライン 5.1.1）。そこで `support.html` を作り、アプリの画面下にリンクを置いた。

## 対象ファイル

- `support.html`（新規）… サポートページ。アプリについて・遊び方・よくある質問・プライバシーポリシー・お問い合わせ
- `index.html` … 画面下に「サポート・プライバシーポリシー」のリンクを追加（CSS `.hint a` を含む）

## 変更内容

### support.html

- 見た目はアプリと同じ（紺の地、水色〜紫の見出し）。スマホ幅に合わせて並びが変わる。外部の読み込み（フォント・画像・スクリプト）は無い
- 載せた内容
  - アプリについて: 概要、モード、記録、通信（なし）、料金（無料・広告なし）
  - 遊び方: 操作、宝石・鍵と扉、★の付き方、モード、ヒント
  - よくある質問: 記録が消えた / Level 1 からやり直したい / 音が出ない / 振動しない / デイリーの迷路が友だちと違う
  - プライバシーポリシー（制定日 2026年9月25日）: 個人情報を収集しない、記録は端末の中だけ、通信しない（「結果をシェア」で渡す文面の説明）、変更時の告知
  - お問い合わせ: 提供 ltv.work、メール ai@ltv.work（mahjong のサポートページと同じ）
- 「ブラウザで遊ぶ」ボタンでアプリに戻れる
- 公開 URL: https://kiyotake1229.github.io/maze-puzzle/support.html （プライバシーポリシーは `#privacy`）

### アプリ内のリンク

- 画面の一番下に「サポート・プライバシーポリシー」を追加（控えめな色。マウスを乗せると明るくなる）
- リンク先は本番の URL（絶対パス）で、新しいタブで開く。iOS アプリの中から押した場合は Safari で開く（アプリの中に別ページが開いて戻れなくなるのを避けるため）
