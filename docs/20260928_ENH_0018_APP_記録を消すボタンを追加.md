# 記録を消すボタンを追加

- 管理番号: #0018
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-28
- 関連: #0001（「記録や実績を消すボタンは無い」と記載）

## 概要

最速タイム・通算の記録・実績などを消す手段がなかった。実績画面に「記録を消す」ボタンを追加した。誤って押しても消えないよう、3秒以内に2回押したときだけ消す。

## 対象ファイル

- `index.html` … 実績画面のボタン（`#resetBtn`）、CSS（`.btn.ghost.subtle`）、`resetRecords`（新規）

## 変更内容

- 実績画面の「閉じる」の横に、控えめな色で「記録を消す」を置いた
- 1回押すと、文字が「もう一度押すと全部消えます」に変わる。3秒以内にもう一度押すと消える。3秒たつと元の表示に戻る
- 消すもの: 端末に保存した `maze_` で始まる記録すべて（各レベルの最速タイム、通算のクリア数・★・宝石、実績、モードごとの進み具合、デイリーの最速）
- 残すもの: 設定（`maze_settings`。モード・テーマ・音・BGM・視界）、案内を見たかどうか（`maze_tutorial` `maze_tip_key`）。`maze_` で始まらない、ほかのアプリの保存データにも触れない
- 消したあとは Level 1 の新しい迷路になり、実績画面は開いたまま（0 / 11 と表示）。「記録を消しました」と出す

## 確認結果

記録がある状態（通算12クリア・実績4個・最速タイム・Level 6・デイリーの最速・テーマ オーロラ）を作り、画面のボタンを押して確かめた。

| 確認したこと | 結果 |
|---|---|
| 実績画面を開く | 「閉じる」と「記録を消す」が並ぶ |
| 「記録を消す」を1回押す | 文字が「もう一度押すと全部消えます」に変わる。記録はそのまま |
| 続けてもう一度押す | 保存が `maze_settings` `maze_tutorial` `maze_tip_key` とほかのアプリのキーだけになる。通算 0、実績 0 / 11、Level 1、画面下の通算表示が消える。テーマはオーロラのまま。「記録を消しました」と表示 |
