# Level を保存し、続きから遊べるようにする

- 管理番号: #0006
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0001（既知の制限「Level を保存しない」）

## 概要

今の Level を保存していなかったため、再読み込みやモードの切り替えで Level 1 に戻っていた。Level をモードごとに保存し、再読み込みしてもモードを切り替えても、続きから遊べるようにした。

## 対象ファイル

- `index.html` … `savedLevel`（新規）、`win`、モードボタンのクリック処理、起動時の処理（スクリプト末尾）
- `README.md` … 主な機能

## 変更内容

- クリアしたら、そのモードで「次に遊ぶ Level」を保存する
  - クリア画面で「次のレベルへ」を押さずに閉じても、次に開いたときは次の Level から始まる
- 起動時は、前回遊んでいたモードの保存済み Level から始める
- モードを切り替えると、そのモードの保存済み Level から始める（これまでは Level 1 に戻っていた）
- 保存値が無い、または壊れている（数字でない・1 未満）ときは Level 1 から始める

### 保存データ（追加分）

| キー | 内容 | 書き込むタイミング |
|---|---|---|
| `maze_level_normal` / `maze_level_time` / `maze_level_hard` | そのモードで次に遊ぶ Level（整数の文字列） | クリア時 |

### 遊び方への影響

- 実績「大冒険家」（Level 11 以上をクリア）が、何回かに分けて遊んでも取れるようになった
- Level 1 に戻す手段は無い。必要になったら、スタート画面に「Level 1 から」を足すなどで対応する
- ワールドが変わったときにテーマが自動で変わる動きは、これまでどおり（設定には保存しない）。再開したときは、利用者が選んだテーマで表示される

## 確認結果

保存データを消した状態から、画面のボタン操作とキー入力で確かめた。

| 操作 | 結果 |
|---|---|
| ノーマル Level 1 をクリアし「次のレベルへ」 | Level 2（10×10）。保存値は 2 |
| そのまま再読み込み | Level 2 から始まる |
| Level 2（鍵あり）をクリアし、「次のレベルへ」を押さずに再読み込み | Level 3 から始まる |
| タイムアタックに切り替え | Level 1（タイムアタックはまだ進めていないため） |
| タイムアタックで Level 1 をクリア | タイムアタックの保存値は 2。ノーマルは 3 のまま |
| スーパーハードに切り替え | Level 1（12×12） |
| ノーマルに戻す | Level 3 から続き |
| タイムアタックにして再読み込み | タイムアタックの Level 2 から始まる |
| 保存値が `abc` / `0` / `-5` / 空 | Level 1 から始まる |
| 保存値 11 で起動し、クリア | Level 11（26×26、WORLD 3）で始まり、クリアで「大冒険家」が解除された |
