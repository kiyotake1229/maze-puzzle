# 通知の枠が画面下からはみ出して見える

- 管理番号: #0008
- 種類: FIX（軽微な修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: なし

## 概要

画面下の通知（実績解除などを知らせる枠）が、何も出ていないときも画面の下端から約10pxはみ出して見えていた。完全に隠れるようにした。あわせて、スマホ幅で通知の文が単語の途中で2行に折り返していたのを、1行で収まるようにした。

## 対象ファイル

- `index.html` … CSS（`.toast`、`.toast.show`）

## 原因

- 隠すときは、自分の高さの 160% だけ下にずらしていた。画面の下端から 24px の位置に置いているので、高さが 40px より低いと隠れきらない。起動直後は文が空で高さが 24px しかなく、約10px が見えていた
- 通知は画面の中央（`left: 50%`）を起点に置いているため、枠の幅が画面の半分までしか広がらなかった。スマホ幅（375px）では 188px になり、「実績解除: スターコ / レクター」のように折り返していた

## 変更内容

- 隠すときのずらし幅を「自分の高さ + 40px」にした。高さに関係なく画面の外に出る
- 隠れているときは透明（`opacity: 0`）にし、出し入れにフェードを付けた（0.3秒）
- 枠の幅を文の長さに合わせ（`width: max-content`）、最大でも画面幅から左右 16px ずつ引いた幅に収める。それより長い文だけ折り返す

## 確認結果

| 確認したこと | スマホ幅（375×812） | デスクトップ幅（673×789） |
|---|---|---|
| 起動直後（文が空） | 画面の外（上端が 828px、画面の高さ 812px）。透明 | 画面の外（上端が 805px、画面の高さ 789px）。透明 |
| 「実績解除: スターコレクター」を表示 | 1行（高さ 45px）、中央に表示 | 1行（高さ 45px） |
| 「スーパーハードは常に暗闇です」「結果をコピーしました」を表示 | どちらも1行、中央に表示 | — |
| 画面幅より長い文を表示 | 左右 16px の余白を残して折り返す | — |
| 表示が終わった後 | 画面の外。透明 | 画面の外。透明 |

修正前は、スマホ幅で「実績解除: スターコレクター」の枠が幅 188px・高さ 66px（2行）だった。
