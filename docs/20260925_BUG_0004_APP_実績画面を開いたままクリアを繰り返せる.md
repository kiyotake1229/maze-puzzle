# 実績画面を開いたままクリアを繰り返せる

- 管理番号: #0004
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0001（「実績一覧を開いている間も迷路を動かせる」と記載。その結果起きる問題は未記載だった）

## 概要

クリア後に実績画面を開くと、キーや十字ボタンで自分を動かせた。ゴールから出て戻るたびにクリア扱いになり、通算クリア数・★・宝石が増え続け、実績も解除できてしまった。実績画面を含め、どの重ね画面が出ている間も動けないようにした。

## 対象ファイル

- `index.html` … `move`

## 原因

- `move` は、重ね画面のうち `#overlay`（スタート・クリア・時間切れ）が出ているかだけを見ていた
- 実績画面（`#achvOverlay`）を開くと `#overlay` は一時的に隠れるので、その間は動けた
- クリア後はタイマーが止まっているため、動き出すとタイマーが0から始まる。ゴールへすぐ戻ると `win` がもう一度呼ばれ、次のことが起きた
  - 通算クリア数・★・宝石が、そのたびに加算される（取った宝石も数え直される）
  - 通算の数を条件とする実績（迷路マスター、宝石王、スターコレクターなど）が解除できる
  - 最速記録が 0.1 秒前後で上書きされる

修正前の本番と同じコードで、クリア画面から実績を開き、←→ を押すだけで再現した（★が 8 → 10 になり、「スターコレクター」が解除された）。

## 変更内容

- `move` で見る条件を「`#overlay` が出ている」から「重ね画面（`.overlay`）のどれかが出ている」に変えた
- 遊んでいる途中で実績画面を開いた場合も、閉じるまでは動かない。実績画面を開いている間もタイマーは進む（これまでと同じ）

## 確認結果

| 確認したこと | 結果 |
|---|---|
| クリア後に実績画面を開き、矢印キーを上下左右に押す | 動かない。通算クリア数・★・宝石は変わらない |
| 同じ状態で十字ボタン（タッチ端末だけに表示）を押す | 動かない |
| 実績画面を閉じる | クリア画面に戻る |
| 遊んでいる途中で実績画面を開き、矢印キーを押す | 動かない |
| 実績画面を閉じてから矢印キーを押す | 普段どおり動く |
