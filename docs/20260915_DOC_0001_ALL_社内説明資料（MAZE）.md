## 概要

「MAZE」（レベル制の迷路パズル）を岩崎さんに説明するためのスライド（7枚）。ねらい（最小構成でゲームとして成立させる）、遊び方と4モード、続ける仕掛け、画面の構成、現状（PWA・iOSは未対応）、iOS化の手順と費用をまとめている。

- `tools/slides/Main.dc.html` / `tools/slides/S02〜S07.dc.html` / `tools/slides/canvas.json`（生成物。Claude Design に載せる）

### 3. 作り直す方法

`tools/slides/gen.py` の文言を直して、アプリのフォルダで次を実行する。スライド・PDF の両方が更新される。

```bash
python3 tools/slides/gen.py
```

```bash
bash docs/manager/generate_docs_json.sh
```

Claude Design（公開URL）も同じ内容にするときは、生成された `tools/slides/*.dc.html` と `canvas.json` で再公開する。
