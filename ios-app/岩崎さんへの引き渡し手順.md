## 3. ビルド手順

このフォルダ（`ios-app/`）で、以下を順に実行してください。

```bash
# 1) 依存パッケージを取得（Dropbox を軽くするため node_modules は消してあります）
npm install

# 2) アプリ本体を同梱し、iOS 用の部品を取り込む（中で pod install が動きます。Xcode が必要）
npm run sync

# 3) Xcodeで開く
open ios/App/App.xcworkspace
```

> **注意**: 必ず `App.xcworkspace` を開いてください（`App.xcodeproj` ではありません）。

### Xcode上での設定

1. 左ペインで **App** を選択 → **Signing & Capabilities** タブ
2. **Team** に自社のApple Developerアカウントを選択（"Automatically manage signing" はON）
3. 必要に応じて **Bundle Identifier** を自社のものに変更
4. **General** タブで **Version**（1.0）と **Build**（1）を確認

### 動作確認

上部のデバイス選択から実機またはシミュレータを選び ▶ で起動。次の点を見てください。

- 起動画面（紺の地に迷路の絵）のあと、スタート画面が出る
- スワイプで一気に進む。画面下の十字ボタンでも動く
- 壁にぶつかる・宝石・鍵・クリア・時間切れで振動する（**実機のみ**。シミュレータでは振動しません）
- 上のステータスバー（時刻・電池）の文字が白で見える
- iPhone では縦向きのまま回転しない
- 画面下の「サポート・プライバシーポリシー」を押すと Safari でサポートページが開く

## 4. App Store申請

1. Xcode: **Product → Archive**
2. Organizerが開いたら **Distribute App → App Store Connect** でアップロード
3. [App Store Connect](https://appstoreconnect.apple.com) でアプリ情報を入力して審査提出

### 申請情報（下書き）

**アプリ名**
```
MAZE - 迷路パズル
```

**サブタイトル（30字以内）**
```
スワイプで駆け抜ける日替わり迷路
```

**説明文**
```
自動で作られる迷路を、スワイプで一気に駆け抜けるパズルゲームです。宝石を集め、鍵で扉を開けてゴールを目指しましょう。毎日変わる「デイリー迷路」は、同じ日なら誰でも同じ迷路。タイムを友だちと競えます。

■ 一気に進む、爽快な操作
1回のスワイプで、壁や分かれ道に着くまで一気に進みます。迷わず駆け抜けるほど速くクリアできます。

■ 4つのモード
・ノーマル：クリアするたびに迷路が広くなる
・タイムアタック：制限時間内にゴールを目指す
・スーパーハード：自分の周りしか見えない暗闇の迷路
・デイリー：その日だけの迷路で最速タイムに挑戦

■ ★3つを目指そう
宝石を全部集め、遠回りせずにゴールすると★3。ヒントは1つの迷路で3回まで（使うと★は2つまで）。

■ 実績・テーマ・触覚
11種類の実績、4つのカラーテーマ（ネオン・オーロラ・サンセット・モノ）、効果音とBGM、手に伝わる触覚フィードバック。

■ 安心して遊べる
アカウント登録・広告・課金はありません。完全オフライン動作。データは端末内にのみ保存され、外部に送信されません。
```

**キーワード（100字以内・カンマ区切り）**
```
迷路,パズル,脳トレ,暇つぶし,デイリー,タイムアタック,スワイプ,オフライン,無料,謎解き,メイズ,ひとり用
```

**カテゴリ**
- プライマリ: ゲーム（サブカテゴリ: パズル、カジュアル）
- セカンダリ: 任意（例: エンターテインメント）

**年齢制限**: 4+（年齢制限の質問はすべて「なし」で 4+ になります）

**著作権**
```
2026 ltv.work
```

## 6. アプリ内容を修正したい場合

アプリ本体は 1つ上のフォルダの `index.html` です。修正後、このフォルダで：

```bash
npm run sync
```

を実行するとiOSプロジェクトに反映されます。その後Xcodeで再ビルドしてください。
2回目以降の申請では、Xcode の **General** で **Build** の数字を1つ上げてください（Version を上げる場合は Build を 1 に戻してもかまいません）。

アイコンや起動画面を変える場合は、1つ上のフォルダの `icon.svg` を直してから、次を実行します。

```bash
# 1つ上のフォルダ（MAZE/）で
bash tools/make-icons.sh
# このフォルダ（ios-app/）で
npm run icons
```
