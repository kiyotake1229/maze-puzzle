## 概要

「1回の操作で壁か分かれ道まで一気に進む」という動きは、初めての人が戸惑いやすい。初めて遊ぶときだけ、スタート直後に進める方向を指す矢印と説明を出すようにした。鍵が初めて出てくる迷路でも、鍵の役割をひとこと知らせる。

## 対象ファイル

- `index.html` … 操作案内の部品（`#coach`）と CSS（`.coach`、矢印の動き `@keyframes nudge`）、`showCoach` `hideCoach` `keyTip`（新規）、`startGame`、`move`、`newLevel`

## 変更内容

### 操作案内（初回だけ）

- 出す条件: まだ一度もクリアしていない、かつ案内を見たことがない
- スタートを押した直後、自分の丸のすぐ横（動ける側）に、黄色の矢印（SVG）と吹き出しを出す
  - 矢印は、スタート地点から動ける方向を向き、その方向に軽く揺れる
  - 吹き出し: 「スワイプで、壁か分かれ道まで一気に進む」（スマホ）／「矢印キーで、壁か分かれ道まで一気に進む」（PC）、その下に小さく「右下の緑の丸がゴール」
- 1手動くと消え、以後は出さない（保存キー `maze_tutorial`）
- 案内が出ている間も、スワイプなどの操作はそのまま効く（案内は押せない飾り）
- 別の迷路になったとき（モード切り替え・やり直す）は消す。この場合はまだ見ていない扱いなので、次に起動したときにもう一度出る

### 鍵の案内（初回だけ）

- 遊んでいる途中で鍵のある迷路が初めて出たとき（ふつうは Level 2）、画面下に「鍵を取ると、赤い扉が開きます」と出す
- 以後は出さない（保存キー `maze_tip_key`）

## 確認結果

| 確認したこと | 結果 |
|---|---|
| 記録なしで起動してスタート（PC 幅） | 自分の丸の右に右向きの矢印と「矢印キーで、壁か分かれ道まで一気に進む／右下の緑の丸がゴール」が出る |
| 1手動く | 案内が消え、`maze_tutorial` が保存される |
| 下にしか進めない迷路 | 矢印が下を向き、自分の丸の下に出る |
| スマホ幅（375×812） | 「スワイプで、…」になり、盤面の中に収まる |
| 再読み込みしてスタート | 案内は出ない |
| Level 1 から Level 2 へ | 「鍵を取ると、赤い扉が開きます」と出る。次の Level 3 では出ない |
