## 1. 1分版（エレベーターピッチ）

> レベル制の迷路パズルです。スワイプでゴールを目指す、それだけ。
>
> ねらいは **「最小の構成でゲームとして成立するもの」** を1本持っておくこと。
> 単一HTMLで約54KB。画像も音源もなく、全部コードで描いて鳴らします。開いた瞬間に遊べて、通信なしで動きます。
>
> テーマ4種、実績11種、タイムアタックと暗闇の視界モードで、「もう1面」の理由を作っています。
> Web版は公開済み。アイコンとPWA対応がまだなので、iOS化するなら1日あれば申請の手前まで届きます。

### 2-1. 何のアプリか・ねらい（30秒）

- 迷路パズル。レベル制で、クリアすると次へ
- ねらいは「最小構成」。54KB、待ち時間ゼロ、ルール説明不要。iOS化のラインナップに最短で足せる1本

### 2-2. デモ（1分30秒）※台本

**① 1面クリア（30秒）**
> 「開いた瞬間に遊べます。スワイプで動く。通った道は軌跡で残るので迷いません」（1面クリア）
> 「宝石を拾うと実績につながります。詰まったらヒントで道筋が光ります」

**② テーマと視界モード（30秒）**
> 「テーマは4種。気分で切り替えます」（切り替える）
> 「視界モードにすると自分の周りしか見えなくなる。スーパーハードでは常時これです」（視界ONで少し動く）

**③ 実績（15秒）**
> 「実績は11種。クリア数・宝石・タイム・視界モードなど、遊び方ごとに解除されます」

**④ 機内モード（15秒）**
> （機内モードにする）「このまま動きます。通信なし、端末内保存です」

### 2-3. 現状（30秒）

- Web版 完成・公開中。通信なし・端末内保存
- レベル制、4モード、テーマ4種、実績11種、ヒント、効果音・BGM
- **未対応**：アイコン、PWA（manifest / Service Worker）、触覚フィードバック

### 2-4. 次のステップとお願い（30秒）

- アイコンとPWA対応で半日、Capacitor で iOS 化に半日。合計1日で申請の手前まで
- 費用は Apple Developer Program（年12,800円）だけ。素材もサーバーもなし
- **お願いしたいこと**：MAZE を iOS 化のラインナップに入れるか。軽いので「申請する本数」を増やす候補になる

## 3. 想定質問と答え

| 質問 | 答え |
|---|---|
| ゲームとして薄くない？ | 単体で売るというより、ラインナップの「数」と「軽さ」を担う1本。テーマ・実績・タイムアタック・視界モードで、遊びの軸は複数ある |
| なぜPWA未対応？ | 最小構成を優先して後回しにしていた。manifest と Service Worker は麻雀のものを写して書き換えるだけで半日 |
| 審査4.2（WebViewだけのアプリ）は？ | 完全オフライン・端末内保存・継続利用（レベルの進行・実績）。iOS化時に触覚フィードバックを組み込む。コツコツと同じ根拠 |
| データは？ | 端末内のみ（進み具合・実績・設定）。通信ゼロ。App Store のプライバシーは「収集しません」 |
| 音は？ | 効果音・BGMは Web Audio で合成。音源ファイルなし。設定でそれぞれON/OFF |
| 子ども向け？ | 誰でも遊べる。年齢制限は 4+ |
| Android は？ | Web版がそのまま動く。PWA対応後はホーム画面追加も可能。必要なら Capacitor で Android も生成できる |
| フォルダの `maze-artifact.html` は？ | 以前の Artifact 公開用のコピーで、今は不要。`index.html` と同期していないので削除してよい（README に記載） |

## 4. 話し方のコツ

- 「軽い」「すぐ遊べる」「1日でiOS化」の3点を最初に言う
- デモは短く。1面クリア → テーマ切替 → 視界モード、で1分半
- 「未対応」は先に自分から言う（アイコン・PWA・触覚）。隠さない方が信頼される
- 最後は「ラインナップに入れるか」の判断を仰いで終わる
