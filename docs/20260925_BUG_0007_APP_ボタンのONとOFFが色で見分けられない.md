# ボタンの ON と OFF が色で見分けられない

- 管理番号: #0007
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0005（視界ボタンの固定表示。この修正で ON の色付き表示が実際に効くようになった）

## 概要

操作ボタン（モード・やり直す・ヒント・視界・テーマ・音・BGM・実績）が、ON・OFF に関係なく全部同じ色付きの見た目になっていた。CSS の優先順位の問題で、控えめな見た目にするための指定が効いていなかった。指定が効くようにし、ON のボタンだけが色付きで表示されるようにした。

## 対象ファイル

- `index.html` … CSS（`.ghost` の3つの指定）

## 原因

- ボタンの基本の見た目は `button.btn`（要素名 + クラス1つ）で、色付きの背景・影・大きめの文字と余白を指定している
- 操作ボタン用の控えめな見た目は `.ghost`（クラス1つ）で指定していた。CSS は、条件の細かい指定が優先される。`.ghost` は `button.btn` より優先度が低く、背景・文字色・影・余白・文字の大きさがすべて上書きされていた
- そのため `.ghost.on`（ON のとき色付き）と、OFF のときの見た目が同じになっていた。「音 ON」と「BGM OFF」が同じ見た目だった
- 修正前の計測: 「音 ON」と「BGM OFF」の背景が、どちらも同じグラデーションだった

## 変更内容

- `.ghost` → `.btn.ghost`、`.ghost:hover` → `.btn.ghost:hover`、`.ghost.on` → `.btn.ghost.on` に変え、`button.btn` より優先されるようにした（指定の中身は変えていない）
- 本来の設計どおりの見た目になる
  - 操作ボタンは半透明の控えめな見た目。文字 12px、余白は小さめ
  - 音・BGM・視界は、ON のときだけ色付き
  - クリア画面は「次のレベルへ」が色付き、「結果をシェア」が控えめになり、どちらを押せばよいかが分かりやすくなった
  - 実績画面の「閉じる」も控えめな見た目になる
- ボタンが小さくなったぶん、スマホ幅（375px）では操作ボタンが4段から3段に収まる

## 確認結果

| 確認したこと | 結果 |
|---|---|
| 起動直後（音 ON、BGM OFF、視界 OFF） | 「音 ON」だけ色付き。ほかは半透明 |
| 音を OFF、BGM を ON、視界を ON にする | 「BGM ON」「視界: ON」が色付き、「音 OFF」が半透明に変わる |
| クリア画面 | 「次のレベルへ」は色付き（14px）、「結果をシェア」は半透明（12px） |
| スーパーハード | 「視界: ON」が色付きで薄い表示（#0005 の固定表示） |
| スマホ幅（375×812） | 操作ボタンは3段。横へのはみ出しなし |
