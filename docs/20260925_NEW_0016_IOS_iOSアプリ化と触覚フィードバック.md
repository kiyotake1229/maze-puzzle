## 概要

Capacitor 7 で iOS プロジェクト（`ios-app/`）を作り、App Store 申請の準備をした。審査ガイドライン 4.2 対策として、触覚フィードバック（壁・宝石・鍵・クリア・時間切れ）を組み込んだ。岩崎さん向けの引き渡し手順書（ビルド手順・申請情報の下書き）も用意した。作成に使った Mac に Xcode が無いため、Xcode でのビルドと実機確認はまだできていない。

## 対象ファイル

- `ios-app/`（新規）… `habit/ios-app/` を雛形にした
  - `package.json` … Capacitor 7（core / ios / haptics）、cli、assets。スクリプト `sync-web` `sync` `open` `icons`
  - `capacitor.config.json` … appId `work.ltv.maze`、appName `MAZE`、背景色 `#0f1226`
  - `sync-web.sh` … 親フォルダの index.html・manifest・アイコンを `www/` にコピー（sw.js はアプリ内で使わないので入れない）
  - `.gitignore` … node_modules / www / Pods / build などを除外
  - `assets/icon-only.png`（1024×1024）、`assets/splash.png` / `splash-dark.png`（2732×2732）… アイコンと起動画面の元画像。`tools/make-icons.sh` で `icon.svg` から作る
  - `ios/` … `npx cap add ios` で作った Xcode プロジェクト。アイコン・起動画面は `npm run icons`（@capacitor/assets）で組み込み済み
  - `岩崎さんへの引き渡し手順.md` … ビルド・署名・申請の手順と、申請情報の下書き
- `index.html` … 触覚フィードバック（`vib`、`NATIVE`、`CAP`）
- `tools/make-icons.sh` … iOS 用の元画像（アイコン・起動画面）の書き出しを追加
- `README.md` … 状態、ファイル構成、iOS化の状況

### 触覚フィードバック（index.html）

- iOS アプリの中（Capacitor）では、Haptics プラグインで振動させる。Web 版はこれまでどおり `navigator.vibrate`（Android のブラウザなど）
- スタート前は振動しない（これまでどおり）

| 場面 | iOS アプリ | Web 版（振動パターン） |
|---|---|---|
| 壁にぶつかる | 衝撃（中） | 30ms |
| 宝石を取る | 衝撃（弱） | 15ms |
| 鍵を取る | 衝撃（中） | 20ms・30ms |
| クリア | 通知（成功） | 25・30・45ms |
| 時間切れ | 通知（エラー） | 60・40・60ms（新規） |

- iOS アプリかどうかの判定（`NATIVE`）は、Service Worker を登録しない判定（#0014）と共通にした

## 確認結果

| 確認したこと | 結果 |
|---|---|
| Web 版の振動 | スタート前は振動しない。スタート後、壁 30・宝石 15・鍵 [20,30] が `navigator.vibrate` に渡る |
| iOS アプリの振動 | Capacitor を模した環境（`isNativePlatform` が true、Haptics を記録する偽物）で index.html を読み込み、壁=衝撃(中)、宝石=衝撃(弱)、鍵=衝撃(中)、クリア=通知(成功)、時間切れ=通知(エラー) の順に呼ばれることを確認。`navigator.vibrate` は呼ばれない |
| アプリに同梱した index.html | 最新の index.html と一致 |
| プラグインの登録 | 生成された設定に `HapticsPlugin` が入っている。Podfile.lock に Capacitor 7.6.9・CapacitorHaptics 7.0.5 |
| Info.plist | `plutil -lint` で書式に問題なし |
| Xcode のプロジェクト設定 | Bundle ID `work.ltv.maze`、Version 1.0、Build 1、iOS 14.0 |
| アイコン・起動画面 | アイコン1枚（1024）と起動画面6枚（通常・ダーク × 1〜3倍）を生成。Contents.json が生成した画像だけを指している |
| Xcode でのビルド・シミュレータ・実機 | **未確認**（Xcode が無いため）。実機での振動の感触も未確認 |
