# 宝石がゴールの奥に置かれて取れない

- 管理番号: #0002
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0001、#0003（★判定。宝石を全部取れることが前提）

## 概要

迷路の約7割でゴールが行き止まりになっておらず、奥に区域ができていた。ゴールに入った瞬間にクリアになるため、その区域に置かれた宝石は取れず、★3 と実績「パーフェクト」が取れない面が約2割あった。迷路を掘り始める位置をゴールに変え、ゴールが必ず行き止まりになるようにした。

## 対象ファイル

- `index.html` … `generateMaze`

## 原因

- 迷路は深さ優先探索（行き止まりまで掘り進めて戻る方式）で、スタート（左上）から掘っていた。角のマスから掘り始めると、そのマスは必ず行き止まりになる。スタートは必ず行き止まりだったが、ゴール（右下）はそうとは限らなかった
- ゴールの隣は上と左の2マスだけ。両方に道がつながると、片方はスタート側、もう片方は「ゴールを通らないと入れない区域」になる
- 宝石はスタートとゴール以外のマスにランダムに置くので、この区域に置かれることがあった
- 鍵はスタートと扉の間にしか置かないので、鍵ではこの問題は起きない

## 変更内容

- `generateMaze` で掘り始めるマスを `cells[0]`（左上）から `cells[cells.length - 1]`（右下＝ゴール）に変えた
- これでゴールは必ず行き止まりになり、奥に区域ができない
- 迷路は「これまでの迷路を180度回したもの」と同じ性質になる。広さや道の長さの傾向は変わらない
- 変わる点: これまで必ず行き止まりだったスタートが、分かれ道になることがある（最初から2方向に進める面がある）

## 確認結果

ゲーム本体の `newLevel` で面を作り、スタートからゴールを通らずに行けるマスを調べた。

| 迷路 | 修正前: 宝石が取れない面（各2000面） | 修正後 |
|---|---|---|
| 8×8（Level 1） | 26.6% | 0件 / 600面 |
| 10×10（Level 2） | 21.3% | 0件 / 600面 |
| 12×12（Level 3、スーパーハード Level 1） | 25.8% | 0件 / 1000面 |
| 16×16（Level 5） | 22.5% | 0件 / 400面 |
| 20×20（スーパーハード Level 5） | 18.7% | 0件 / 200面 |
| 26×26（Level 10） | 15.3% | 0件 / 200面 |
| 30×30（スーパーハード Level 10） | 13.4% | 0件 / 150面 |

- 修正後は、どの面でもゴールの道は1本だけ（行き止まり）だった
- 修正前の「ゴールの奥に区域がある面」は、大きさによらず約7割だった
