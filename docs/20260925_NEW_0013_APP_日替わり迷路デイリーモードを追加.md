# 日替わり迷路（デイリーモード）を追加

- 管理番号: #0013
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0011（ヒントの制限はデイリーにも適用）、#0003（★の付け方）

## 概要

日付ごとに全員が同じ迷路で遊べる「デイリー」モードを追加した。同じ迷路でタイムを比べられるので、結果をシェアする意味が出る。毎日遊ぶきっかけにもなる。

## 対象ファイル

- `index.html` … `mulberry32`・`todayKey`・`dailyLabel`・`bestKeyFor`（新規）、状態変数 `rand` `dailyKey`（新規）、`generateMaze`・`newLevel`・`placeKeyDoor`（乱数を `rand` に変更）、`win`、`updateStats`、`updateBest`、`shareResult`、`showStart`、モードボタン、`loadSettings`、数値バーの見出し（`#lvLabel`）
- `README.md` … 主な機能

## 仕様

- モードボタンの切り替えは「ノーマル → タイムアタック → スーパーハード → デイリー → ノーマル」
- 迷路は端末の日付（年月日）から作る。同じ日なら、どの端末でも同じ迷路になる（迷路・宝石・鍵・扉の位置まで同じ）。日付が変わると別の迷路になる
- 迷路は 16×16、鍵と扉あり、宝石3個。時間制限なし（経過時間を表示）
- 数値バーの「Level」は「Daily」と日付（例: 9/25）になる。サブタイトルは「迷路パズル ・ デイリー 9/25」
- 「Best」はその日の最速タイム（保存キー `maze_daily_<年月日>`、例: `maze_daily_20260925`）
- 「やり直す」とクリア画面の「もう一度」は、同じ迷路を最初から遊び直す
- クリア画面
  - その日の初回クリア: 「DAILY CLEAR!」
  - 2回目以降: 記録を更新したら「NEW RECORD!」、それ以外は「CLEAR!」
  - 「デイリー 9/25 ・ 4.5秒 ・ 184手」のように表示
- 通算のクリア数・★・宝石に加えるのは、その日の初回クリアだけ（同じ迷路を繰り返して実績を稼げないように）
- デイリーは Level の保存（#0006）の対象外。スタート画面の「続きから」「Level 1 から」（#0010）も出さない
- シェアの文面: 「MAZE デイリー 9/25 を ★3 / 4.5秒 でクリア! 迷路パズル」＋URL
- ヒント（#0011）は3回まで。視界の ON/OFF は利用者の設定に従う

### 同じ迷路を作る仕組み

- これまでは迷路・宝石・鍵の配置に `Math.random`（毎回ちがう乱数）を使っていた。デイリーのときだけ、日付（例: 20260925）を種にした乱数（mulberry32 という計算式）に切り替える
- この計算は整数演算だけなので、端末やブラウザが違っても同じ結果になる
- 注意: 迷路を作る処理（`generateMaze`・宝石の配置・`placeKeyDoor`）を変えると、同じ日付でも迷路が変わる。アプリを更新した日は、更新前と更新後の端末で迷路が一致しないことがある

## 確認結果

画面のボタン操作とキー入力で確かめた（2026-09-25）。

| 確認したこと | 結果 |
|---|---|
| モードボタンを3回押す | 「モード: デイリー」。数値バーは「Daily 9/25」、16×16、鍵あり、宝石3個、「Time」表示 |
| 「やり直す」 | 同じ迷路（壁・宝石・鍵・扉がすべて一致） |
| 日付を 9/26 に差し替えて作る | 別の迷路になる |
| 日付を 9/25 に戻して作る | 元と同じ迷路 |
| ノーマルで2回作る | 毎回ちがう迷路（これまでどおり） |
| 再読み込み | デイリーのまま起動し、同じ迷路。スタート画面は「スタート」だけ |
| 宝石を全部取ってクリア（初回） | 「DAILY CLEAR!」、★3、「デイリー 9/25 ・ 4.5秒 ・ 184手」、ボタンは「もう一度」。通算クリア 1・★3・宝石3。最速 4.5 秒を保存 |
| 結果をシェア | 「MAZE デイリー 9/25 を ★3 / 4.5秒 でクリア! 迷路パズル」＋URL |
| 「もう一度」でより速くクリア | 同じ迷路。「NEW RECORD!」。通算の数は増えない。最速を更新 |
| デイリーからノーマルに戻す | 保存していた Level 4（14×14）から。見出しは「Level」、サブタイトルは「WORLD 1」 |
