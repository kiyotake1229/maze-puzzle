# 「MAZE」プレゼンの進め方（話す内容メモ）

岩崎さんに説明するときの台本。**3分版**を基本に、時間がなければ「1分版」だけでも伝わるようにしてある。
スライド（ https://claude.ai/code/artifact/dad654fa-2ff3-4609-8119-1cb7d7a42d57 ）を画面に出し、手元のスマホでデモする想定。

（2026-09-28 更新: PWA 対応・iOS の申請準備・デイリーなど、9/15 以降の変更を反映）

## 0. 準備チェック（前日〜直前）

- [ ] スマホで https://kiyotake1229.github.io/maze-puzzle/ を開き、共有メニューから「ホーム画面に追加」しておく（アプリとして全画面で開く。一度開けば通信なしでも起動する）
- [ ] 何面かクリアして、実績がいくつか解除された状態にしておく
- [ ] デイリー（モードボタンを3回）を1回クリアしておく（「連続 1日」が付く）
- [ ] 音量を確認（効果音・BGM）
- [ ] スライドをPCのブラウザで開いておく。ネットが不安なら `プレゼン資料/MAZE_社内説明.pdf` を開く
- [ ] 見せられるように、App Store 用スクリーンショット（`../ios-app/screenshots/iphone-6.9/`）を開いておく

## 1. 1分版（エレベーターピッチ）

> 迷路パズルです。スワイプすると、壁か分かれ道まで一気に進む。それだけ。
>
> ねらいは **「最小の構成でゲームとして成立するもの」** を1本持っておくこと。
> 単一HTMLで約57KB。画像も音源もなく、全部コードで描いて鳴らします。通信なしで動きます。
>
> 毎日かわる「デイリー迷路」と連続記録、実績14種、テーマ4種で、毎日開く理由を作っています。
> Web版と PWA は完成。iOS はプロジェクト・スクリーンショット・申請文まで用意したので、あとは Xcode でビルドして申請するだけです。

### 2-1. 何のアプリか・ねらい（30秒）

- 迷路パズル。レベル制で、クリアすると次へ。進み具合は保存され、続きから遊べる
- ねらいは「最小構成」。57KB、待ち時間ゼロ、ルール説明不要（初回だけ矢印でひとこと案内）

### 2-2. デモ（1分30秒）※台本

**① 1面クリア（30秒）**
> 「ホーム画面から開くと、アプリとして全画面で起動します。スワイプすると、壁か分かれ道まで一気に進む。通った道は跡が残るので迷いません」（1面クリア）
> 「宝石を全部取って、遠回りしなければ★3。鍵を取ると赤い扉が開きます」

**② デイリー（30秒）**
> 「デイリーは日替わりの迷路で、同じ日なら全員同じ迷路です。タイムを比べられて、毎日クリアすると連続記録が伸びます」（デイリーを見せる）
> 「iOS 版では毎朝8時に『今日の迷路』を通知できます」

**③ 暗闇と実績（15秒）**
> 「スーパーハードは自分の周りしか見えません」（少し動く）「実績は14種。デイリーの連続でも解除されます」

**④ 機内モード（15秒）**
> （機内モードにして、ホーム画面から開き直す）「このまま起動して遊べます。通信なし、端末内保存です」

### 2-3. 現状（30秒）

- Web版 完成・公開中。PWA 対応済み（ホーム画面に追加、通信なしで起動）
- 4モード（ノーマル・タイムアタック・スーパーハード・デイリー）、テーマ4種、実績14種、連続記録、ヒント、効果音・BGM
- iOS: プロジェクト作成済み（触覚フィードバック・毎朝の通知）。スクリーンショット・申請文・サポートページも用意
- **未確認**: Xcode でのビルドと実機での動作（作った Mac に Xcode が無いため）。先に自分から言う
- 自動テスト22件。修正と改善の記録は docs に22件

### 2-4. 次のステップとお願い（30秒）

- 手順書（`ios-app/岩崎さんへの引き渡し手順.md`）のとおりに Xcode でビルドして、実機で振動と通知を確認（半日）
- App Store Connect に、用意した文面とスクリーンショットを入れて提出（1〜2時間）
- 費用は Apple Developer Program（年12,800円）だけ。素材もサーバーもなし
- **お願いしたいこと**：MAZE を申請に進めるか。進めるなら、署名とアップロードをお願いしたい

## 3. 想定質問と答え

| 質問 | 答え |
|---|---|
| ゲームとして薄くない？ | 単体で売るというより、ラインナップの「数」と「軽さ」を担う1本。そのうえで、デイリーと連続記録・実績・4モードで、毎日遊ぶ理由を作っている |
| iOS でちゃんと動く？ | 作った Mac に Xcode が無く、ビルドは未確認。アプリ本体は Web で確認済みで、iOS の振動・通知の呼び出しも模した環境で確認した。ビルドで問題が出たらすぐ直す |
| 審査4.2（WebViewだけのアプリ）は？ | 完全オフライン・端末内保存・継続利用（レベル・デイリー・実績）。ネイティブ機能として触覚フィードバックと毎朝の通知を入れた。コツコツと同じ根拠 |
| データは？ | 端末内のみ（進み具合・実績・設定）。通信ゼロ。App Store のプライバシーは「収集しません」。サポートページにプライバシーポリシーを載せた |
| デイリーって？ | 日付から迷路を作るので、同じ日なら誰でも同じ迷路。タイムを友だちと比べられる。シェアの文面に日付と連続日数が入る |
| 音は？ | 効果音・BGMは Web Audio で合成。音源ファイルなし。設定でそれぞれON/OFF |
| 子ども向け？ | 誰でも遊べる。年齢制限は 4+ |
| Android は？ | Web版がそのまま動き、ホーム画面にも追加できる（PWA）。必要なら同じ作りで Android アプリも作れる |
| フォルダの `maze-artifact.html` は？ | 以前の Artifact 公開用の古いコピー。不要になったので 2026-09-25 に削除した（docs #0009） |

## 4. 話し方のコツ

- 「軽い」「毎日遊べる」「申請の準備は済み」の3点を最初に言う
- デモは短く。1面クリア → デイリー → 暗闇、で1分半
- 「未確認」（Xcode でのビルド）は先に自分から言う。隠さない方が信頼される
- 最後は「申請に進めるか」の判断を仰いで終わる
