# ヒントに回数制限を付け、使うと★を2つまでにする

- 管理番号: #0011
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-25
- 関連: #0003（★の付け方）

## 概要

ヒントは何回でも使え、★にも影響しなかったため、手応えが薄くなっていた。1つの迷路で使える回数を3回（スーパーハードは1回）にし、使った迷路の★は最大2つにした。

## 対象ファイル

- `index.html` … `showHint`、`newLevel`、`win`、`updateHintBtn`（新規）、状態変数 `hintsLeft` `hintUsed`（新規）

## 変更内容

- 使える回数: 1つの迷路につき、ノーマル・タイムアタックは3回、スーパーハードは1回。新しい迷路になる（次のレベル・やり直す・リトライ・モード切り替え）と回数は戻る
- ボタンに残り回数を出す（「ヒント 残り3」）。0 になるとボタンを薄く表示し、押すと「この迷路のヒントは使い切りました」と出す
- ヒントを表示したあと、動かずにもう一度押した場合は回数を減らさない（同じ道が出るだけのため）
- 最初に使ったとき「ヒントを使ったので、この迷路の★は2つまで」と知らせる
- ヒントを使った迷路は、★を最大2つにする。クリア画面に「ヒント使用（★は2つまで）」と出す。実績「パーフェクト」（★3）も、ヒントなしでクリアしたときだけになる
- スタート画面・クリア画面・実績画面が出ている間は、ヒントを押しても何もしない（これまではスタート前でもヒントが出ていた）

### この形にした理由

- ヒントは1回でゴールまでの道が全部見えるため、回数を絞るだけでは手応えが戻らない。「使うと★3 にならない」ことで、自力で解く価値を残した
- 回数はあるので、詰まった人は先に進める（遊びやすさは残す）
- スーパーハードは暗闇でヒントの効き目が大きいため、1回にした

## 確認結果

画面のボタン操作とキー入力で確かめた。

| 確認したこと | 結果 |
|---|---|
| スタート前にヒントを押す | 何も起きない（残り3のまま） |
| 1回目 | 「ヒント 残り2」。道が表示され、★の注意が出る |
| 動かずにもう一度押す | 残り2のまま |
| 動いてから押す（2回・3回目） | 残り1、残り0。0 でボタンが薄くなる |
| 残り0で押す | 「使い切りました」と出て、道は出ない |
| ヒントを使い、宝石を全部取る最短ルート（44手）でクリア | ★2。「ヒント使用（★は2つまで）」と表示 |
| やり直す | 残り3に戻る |
| スーパーハード | 「ヒント 残り1」 |
