# 毎朝の「今日の迷路」通知（iOS アプリ）

## 概要

iOS アプリ版に「毎朝の通知」ボタンを追加した。ON にすると、毎朝8時に「今日の迷路が届きました」と通知し、押すとデイリーモードで開く。デイリーの連続記録を続けるきっかけになり、App Store 審査（ガイドライン 4.2）で示せるネイティブ機能も増える。通知は端末の中で予約するローカル通知で、外部とは通信しない。

## 変更内容

- 操作ボタンの最後に「毎朝の通知: OFF」を置く。**iOS アプリの中でだけ表示**し、Web 版では出さない
- ON にするとき、通知の許可を求める
  - 許可された: 毎朝8時0分に繰り返す通知を予約する（id 2001、本文「今日の迷路が届きました。最速タイムに挑戦しよう」）。「毎朝8時に、今日の迷路をお知らせします」と表示
  - 許可されなかった: 「通知が許可されていません（設定アプリで許可できます）」と表示し、OFF のまま
- OFF にすると予約を取り消し、「通知を止めました」と表示
- ON/OFF は設定（`maze_settings` の `notifyOn`）に保存する。初期値は OFF
- 起動時、ON なら予約をいったん取り消してから入れ直す（二重に届かないように）
- 通知を押してアプリを開くと、デイリーモードに切り替える。まだスタート前なら、スタート画面を出す
- 予約の仕組み: プラグインの `schedule.on`（時・分）を使う。iOS では毎日同じ時刻に繰り返す通知になる（プラグインの iOS 側の実装で、`UNCalendarNotificationTrigger` を `repeats: true` で作ることを確認）

## 確認結果

Capacitor を模した環境（iOS アプリの中と同じく `isNativePlatform` が true、通知プラグインの呼び出しを記録する偽物）で index.html を読み込んで確かめた。

| 確認したこと | 結果 |
|---|---|
| iOS アプリとして起動（通知 OFF） | 「毎朝の通知: OFF」が出る。起動時の予約はしない |
| 押す（許可する） | 許可の確認 → 予約の取り消し → 毎日8時0分の予約。ボタンは ON、設定に保存 |
| もう一度押す | 予約を取り消す。ボタンは OFF、設定に保存 |
| 押す（許可しない） | 「通知が許可されていません（設定アプリで許可できます）」と出て、予約しない。OFF のまま |
| ON のまま起動し直す | 予約を入れ直す。ボタンは ON。通知を押したときの受け口を登録する |
| 通知を押して開く（ノーマルで、スタート前） | デイリーモードに切り替わり、スタート画面が出る |
| Web 版 | ボタンは表示されない |
| iOS プロジェクト | 生成された設定に `LocalNotificationsPlugin` が入り、Podfile.lock に CapacitorLocalNotifications 7.0.7。同梱の index.html は最新 |

- 実機で通知が届くこと・表示は未確認（この Mac に Xcode が無いため）。手順書の3章に、端末の時刻を進めて確かめる方法を書いた
