## 仕様

### 画面と機能

1画面のアプリ。上から「タイトル」「数値バー」「迷路」「操作ボタン」「十字ボタン」「案内文」の順に並ぶ。スタート・クリア・時間切れ・実績一覧は、迷路の上に重ねて表示する。

#### 画面の部品

| 部品 | できること | 関数名・HTML の id |
|---|---|---|
| スタート画面 | 起動時に表示。「スタート」で遊び始める。音の準備と BGM の開始もここ | `showStart`、`#overlay` |
| 数値バー | Level、経過時間（時間制限のあるモードでは残り時間 `Left`）、Moves、Best（そのレベル番号の最速タイム） | `#lv` `#time` `#timeLabel` `#moves` `#best` |
| サブタイトル | 「迷路パズル ・ WORLD n」 | `#sub` |
| 迷路 | 自分（黄色の丸）を動かしてゴール（緑の丸）へ。通ったマスに跡が残る | `#game`（canvas） |
| 操作ボタン | モード、やり直す、ヒント、視界、テーマ、音、BGM、実績 | `#modeBtn` `#newBtn` `#hintBtn` `#fogBtn` `#themeBtn` `#soundBtn` `#bgmBtn` `#achvBtn` |
| 十字ボタン | タッチ操作の端末だけに表示 | `.dpad` |
| 通算表示 | 通算クリア数・★合計・宝石合計 | `updateProgress`、`#progress` |
| クリア画面 | ★の数、タイム、手数、宝石数。「次のレベルへ」「結果をシェア」 | `win`、`#ov-title` `#ov-msg` `#ov-btn` `#shareBtn` |
| 時間切れ画面 | 「TIME UP」。「リトライ」で同じレベルの新しい迷路 | `timeUp` |
| 実績一覧 | 11種の解除状況と「解除数 / 11」 | `showAchv`、`#achvOverlay` `#badgeList` `#achvCount` |
| 通知 | 実績解除やコピー完了を画面下に出す | `toast`、`#toast` |

#### 操作

- スワイプ（20px 以上）、矢印キー、WASD キー、十字ボタンで動く
- 1回の操作で、壁・分かれ道・ゴールのどれかに着くまで一気に進む（`move`、`hasBranch`）
- Moves と「手数」は、操作の回数ではなく進んだマス数
- タイマーは最初に動いた時点で始まる（`startTimer`）

#### モード

モードボタンを押すたびに「ノーマル → タイムアタック → スーパーハード → ノーマル」と変わる。変えると Level 1 に戻る。視界は別のボタンで ON/OFF する。

| モード | 迷路の大きさ | 時間制限 | 鍵と扉 | 暗闇 |
|---|---|---|---|---|
| ノーマル（`normal`） | 基本サイズ | なし（経過時間を表示） | Level 2 から | 視界ボタンに従う |
| タイムアタック（`time`） | 基本サイズ | 最短手数 × 0.9 秒（最低 8 秒） | Level 2 から | 視界ボタンに従う |
| スーパーハード（`hard`） | 基本サイズ + 4（上限 30） | 最短手数 × 0.6 秒（最低 6 秒） | Level 1 から | 常に暗闇 |
| 視界 ON（`fogOn`） | モードに従う | モードに従う | モードに従う | 自分の周り約3マスだけ見える。ゴールの位置はうっすら見える |

- 制限時間は `newLevel` で計算する。鍵がある迷路では「スタート→鍵→ゴール」の距離を最短手数とする
- 残り 6 秒以下で数字の色が変わり、3 秒以下で赤く点滅する（`updateStats`）

#### 迷路の作り方と大きさ

- 毎回ランダムに作る。同じ迷路は再現できない
- 作り方は深さ優先探索（行き止まりまで掘り進めて戻る方式）。どの2マスの間も道は1本だけになる（`generateMaze`）
- 形は正方形。スタートは左上、ゴールは右下
- 1辺のマス数は `8 + (Level - 1) × 2`、上限 26（`sizeForLevel`）。スーパーハードは +4、上限 30（`newLevel`）

| Level | 1 | 2 | 3 | 5 | 10 以降 |
|---|---|---|---|---|---|
| ノーマル・タイムアタック | 8×8 | 10×10 | 12×12 | 16×16 | 26×26 |
| スーパーハード | 12×12 | 14×14 | 16×16 | 20×20 | 30×30 |

- 5レベルで1ワールド（`worldOf`）。5の倍数のレベルをクリアすると「WORLD n 突破!」と出る
- ワールドが変わるとテーマが自動で変わる（1=ネオン、2=オーロラ、3=サンセット、4=モノ、以後くり返し）。BGM の音の高さも変わる（`nextLevel`、`bgmTick`）
- 「やり直す」は、同じ迷路を最初からではなく、同じレベルの新しい迷路を作る（`newLevel` を呼ぶ）

#### 宝石・鍵と扉・スター

- 宝石: 1辺 8〜10 マスの迷路は2個、12 マス以上は3個。スタートとゴール以外にランダムに置く。通るだけで取れる
- 鍵と扉: スタートからゴールまでの最短ルートの真ん中に、赤い線の扉を置く。鍵は扉より手前（スタート側）のどこかに置く。鍵を取ると扉が開く（`placeKeyDoor`、`isDoorEdge`）
- スター（★1〜3）はクリア時に決まる（`win`）
  - 基本は ★1
  - 宝石を全部取ると +1
  - 手数が最短の 1.4 倍以内なら +1。ただし不具合で、ほぼ必ず +1 される（「既知の制限・注意点」参照）
  - そのため実際は「宝石を全部取れば★3、それ以外は★2」になる
- 「NEW RECORD!」は、そのレベル番号の最速タイムを更新したときに出る

#### ヒント

- 押すと、今いる場所からゴールまでの道を線で表示する（`showHint`）
- 鍵を取る前は「鍵を経由してゴール」の道を出す。扉は通らない（`bfsPath`）
- 線は少しずつ薄くなり、次に動くと消える
- 回数制限なし。スターや記録への減点もない

#### テーマ（4種）

テーマボタンで「ネオン → オーロラ → サンセット → モノ」と切り替わる（`themes`、`themeNames`、`applyTheme`）。

| 表示名 | `data-theme` の値 | 色の傾向 |
|---|---|---|
| ネオン | なし（初期値） | 紺の地に水色・紫 |
| オーロラ | `aurora` | 深緑の地に緑・水色 |
| サンセット | `sunset` | 暗い赤紫の地にオレンジ・赤 |
| モノ | `mono` | 黒の地にグレー |

#### 音・振動・シェア

- 効果音: 移動、壁にぶつかる、宝石、鍵、クリア、時間切れ。音声ファイルは使わず、ブラウザの Web Audio で音を合成している。初期値は ON
- BGM: 5音の音階からランダムに選んだ音を 0.82 秒ごとに鳴らす。初期値は OFF。効果音とは別に切り替えるので、「音 OFF」でも「BGM ON」なら BGM は鳴る
- 振動: 壁にぶつかる・宝石・鍵・クリアで振動させる（`vib`、`navigator.vibrate`）。スタート前は振動しない。使えない端末では何も起きない
- シェア: クリア画面の「結果をシェア」で端末の共有機能を開く。共有機能が無い場合は、文面と URL をクリップボードにコピーする（`shareResult`）

#### 実績（11種）

条件は `ACHV` 配列の `test`。判定はクリアした時だけ行う（`checkAchv` を呼ぶのは `win` だけ）。解除すると画面下に「実績解除: 名前」と出る。通算の数は全モード合計で、保存される。

| id | 名前 | 画面の説明 | 実装上の条件 |
|---|---|---|---|
| `first` | はじめの一歩 | 初クリア | 通算クリア数が 1 以上 |
| `clear10` | 迷路マスター | 10ステージクリア | 通算クリア数が 10 以上 |
| `clear30` | 迷宮の主 | 30ステージクリア | 通算クリア数が 30 以上 |
| `gems10` | 宝石ハンター | 宝石を10個集める | 通算宝石数が 10 以上 |
| `gems50` | 宝石王 | 宝石を50個集める | 通算宝石数が 50 以上 |
| `stars10` | スターコレクター | ★を10個獲得 | 通算★が 10 以上 |
| `perfect` | パーフェクト | ★3つでクリア | ★3 でクリア（現状は宝石を全部取れば、ほぼ成立） |
| `speed` | スピードスター | タイムアタックをクリア | タイムアタックでクリア |
| `dark` | 闇を照らす者 | 視界モードでクリア | 暗闇の状態でクリア。スーパーハードのクリアでも解除される |
| `world3` | 大冒険家 | ワールド3に到達 | Level 11 以上をクリア。到達しただけでは解除されない |
| `hardcore` | 不屈の挑戦者 | スーパーハードをクリア | スーパーハードでクリア |

### データの保存

- 保存先はブラウザの localStorage だけ。端末の外には送らない
- 読み書きは `lsGet` / `lsSet` を通す。localStorage が使えない環境では、エラーにせず保存をあきらめる

| キー | 内容 | 書き込むタイミング |
|---|---|---|
| `maze_best_<レベル番号>`（例: `maze_best_3`） | そのレベル番号の最速タイム（秒。小数1桁の文字列）。モード共通 | クリアして記録を更新したとき |
| `maze_total` | 通算クリア数 | クリア時 |
| `maze_gems` | 通算の宝石数 | クリア時 |
| `maze_stars` | 通算の★数 | クリア時 |
| `maze_achv` | 解除した実績（JSON。例: `{"first":1}`） | 実績を解除したとき |
| `maze_settings` | 設定（JSON。`themeIdx` `soundOn` `fogOn` `mode` `bgmOn`） | モード・視界・テーマ・音・BGM を切り替えたとき |

保存しないもの:

- 今の Level（再読み込みすると Level 1 に戻る）
- 遊んでいる途中の迷路

記録や実績を消すボタンは無い。

### 通信と外部リソース

- `index.html` は外部と通信しない。`fetch` などの通信処理、外部スクリプト、CDN、Google Fonts などの Web フォント、外部画像の読み込みは無い
- アイコン（`apple-touch-icon` と `icon`）は、256×256 の PNG を data URI で埋め込んでいる
- フォントは端末の標準フォント（`-apple-system`、`Hiragino Sans` など）
- 「結果をシェア」は、利用者が押したときだけ端末の共有機能かクリップボードを使う。アプリから直接どこかへ送ることはない
- `report.html` は Google Fonts を読み込む（アプリ本体とは無関係）
- 本番は GitHub Pages から配信している。Service Worker が無いので、オフラインで開ける仕組みは入っていない

### 技術構成とコードの地図

- 単一 HTML。ビルド不要。ライブラリ・フレームワークは使っていない
- `<script>` は1つで、`</body>` の直前にある。変数と関数はすべてグローバル
- 迷路は `<canvas id="game">` に 2D で描く。高解像度画面では最大2倍で描く（`DPR`）

- 起動の流れ: スクリプト末尾で `loadAchv` → 通算値の読み込み → `loadSettings` → `updateProgress` → `newLevel` → `showStart`

### 既知の制限・注意点

README・報告書と実装の食い違い（実装を正とする）:

- テーマ名: README は「デフォルト / aurora / mono / sunset」。画面の表示は「ネオン / オーロラ / サンセット / モノ」で、この順に切り替わる
- モード: README は「ノーマル ほか」とだけ書いている。実装は3モード（ノーマル・タイムアタック・スーパーハード）と、別ボタンの視界 ON/OFF
- やり直し: README の「やり直し」は、同じ迷路のやり直しではない。同じレベルで新しい迷路を作る
- オフライン: README は「完全オフライン」。遊んでいる間に通信しないのは正しい。ただし `manifest.json` / `sw.js` が無いので、通信なしで起動できる仕組みは無い
- `report.html`（2026-08-21）は「iPhoneアプリ化（PWA）」「オフライン対応」と書いているが、`manifest.json` / `sw.js` は無い。README の「PWA 未対応」が正しい
- `report.html` の「48 自動テスト通過」: テストのコードはリポジトリに無い。内容は未確認
- 最初のコミットの名前は「MAZE 迷路パズル PWA」だが、中身は `index.html` だけ

実装の不具合・制限:

- スターの「手数」判定が効いていない。`win` の中で `const key = 'maze_best_' + level` と宣言しており、鍵を表すグローバル変数 `key` を隠している。そのため最短手数が常に 1998 と計算され、2797 マス以内でゴールすれば必ず +1 される。実績「パーフェクト」も宝石を全部取ればほぼ解除される（`index.html` のスクリプトを Node.js で動かして確認）
- Level を保存しない。再読み込みやモード切り替えで Level 1 に戻る。そのため「大冒険家」は、1回の連続プレイで Level 11 をクリアする必要がある
- 最速記録 `maze_best_<レベル番号>` はモード共通。迷路は毎回違うので、同じ迷路での比較にはならない
- スーパーハードでは、視界ボタンが「OFF」表示のままでも暗闇になる（`isFog`）
- ワールドが変わるとテーマが自動で変わり、利用者が選んだテーマが上書きされる（このとき設定には保存しない）
- 実績一覧を開いている間も、キーボードと十字ボタンで迷路を動かせる（`move` は `#overlay` しか見ていない）
- iPhone での振動（`navigator.vibrate`）の動作は未確認
- `maze-artifact.html` と `report.html` も本番URLの下で公開されている（`/maze-artifact.html` と `/report.html` が 200 を返す。2026-09-15 確認）

確認の範囲:

- 本番の `index.html` は、ローカルの `index.html` とバイト単位で同じ（2026-09-15 に取得して比較）
- 迷路のサイズ、制限時間、スターの不具合は、スクリプトを Node.js 上で動かして確認した
- ブラウザ画面と実機（iPhone・Android）での動作確認は、この文書の作成時には行っていない（未確認）
