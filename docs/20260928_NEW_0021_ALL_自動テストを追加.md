## 概要

index.html のスクリプトをそのまま Node で動かし、ゲームの決まりごとを確かめる自動テスト `tools/test.mjs` を作った。22件。特にデイリー迷路は、迷路の作り方を少し変えるだけで全員の迷路が変わってしまうため、その日の迷路の「指紋」で変化を検知する。追加のインストールは不要で、`node tools/test.mjs` だけで動く。

## 対象ファイル

## 変更内容

### 仕組み

- index.html から `<script>` の中身を取り出し、Node の `vm`（別の実行環境）で動かす
- 画面の部品（ボタン・canvas・音・保存領域など）は、テストに必要な分だけ偽物で置き換える。保存領域（localStorage）は中身を確かめられる偽物
- テスト用の道具を同じ環境に入れる: 別の書き方の最短ルート計算（答え合わせ用）、最短の操作手順を作る関数、到達できるマスの計算、迷路の指紋
- `MAZE_HTML` で別のファイルを指定できる（わざと壊したコピーでテストが失敗することを確かめる用）
- 全件 OK なら終了コード 0、1件でも NG なら 1

### テストの内容（22件）

| 分類 | 内容 |

| 迷路の形（8件） | ノーマル Level 1/2/5/10、タイムアタック Level 3、スーパーハード Level 1/10、デイリーで、通路が木の形（全マスにつながり、道が1本）、ゴールが行き止まり、宝石がゴールの奥に無い、鍵が扉の手前にある、扉がゴールまでの道の上にある |
