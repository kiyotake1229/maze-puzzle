## 概要

ホーム画面に追加してアプリとして使えるように、`manifest.json`（アプリの名前・アイコンの情報）と `sw.js`（Service Worker。通信なしで起動するための仕組み）を追加した。アイコンは、これまで index.html に埋め込んでいた画像と同じデザインを SVG で作り直し、各サイズの PNG を作った。一度開けば、通信できなくても起動できる。

## 対象ファイル

- `icon.svg`（新規）… アイコンの元データ。これまでの埋め込みアイコン（256×256）と同じデザインを図形で描き直したもの
- `icon-192.png` / `icon-512.png` / `icon-512-maskable.png` / `apple-touch-icon.png`（新規）… `icon.svg` から作った PNG
- `tools/make-icons.sh`（新規）… `icon.svg` から PNG を作り直すスクリプト（`bash tools/make-icons.sh`。要 Node.js）
- `manifest.json`（新規）
- `sw.js`（新規）
- `index.html` … `<head>` のアイコン指定を差し替え、`manifest.json` を読み込む。スクリプト末尾で Service Worker を登録
- `README.md` … 状態とファイル構成

## 変更内容

### アイコン

| ファイル | 大きさ | 用途 |
|---|---|---|
| `icon-192.png` | 192×192 | ホーム画面・ブラウザ |
| `icon-512.png` | 512×512 | インストール画面など |
| `icon-512-maskable.png` | 512×512 | Android などで丸く切り抜かれる場合用。絵を中央に 72% で置き、欠けないようにした |
| `apple-touch-icon.png` | 180×180 | iPhone のホーム画面 |

- 背景は透明にしていない（iOS のアイコンは透明部分があると黒くなるため）
- index.html に埋め込んでいた 2 つの画像（各 約5.8KB）をファイル参照に替えた。index.html は約59KB から約48KB になった

### manifest.json

- 名前「MAZE - 迷路パズル」、短い名前「MAZE」、全画面（`standalone`）表示、背景・テーマ色 `#0f1226`
- 向きは固定しない（iPad の横向きでも使えるように）

### sw.js（Service Worker）

- 初回に開いたとき、アプリ本体・manifest・アイコン（計8ファイル）を端末に保存する
- ページは毎回サーバーに最新を取りに行き、通信できないときだけ保存しておいたものを使う。更新がすぐ反映される
- アイコンなどは保存したものを優先する
- **本番（`kiyotake1229.github.io`）は、ほかの自社アプリ（mahjong・habit など）とキャッシュ置き場を共有している。** そのため、消す・探すのは `maze-` で始まる自分のキャッシュだけにした（ほかのアプリのキャッシュを消さない）
- index.html やアイコンを変えたときは、`sw.js` の `CACHE`（今は `maze-v1`）の番号を上げる。上げなくても、ページ自体は毎回最新を取りに行くので表示は更新される

### 登録

- index.html の最後で `sw.js` を登録する。iOS アプリ（Capacitor）の中と、Service Worker を使えない環境（ファイルを直接開いた場合など）では登録しない、または失敗しても何もしない
