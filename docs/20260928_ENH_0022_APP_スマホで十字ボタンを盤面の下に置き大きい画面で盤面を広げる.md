# スマホで十字ボタンを盤面の下に置き、大きい画面で盤面を広げる

- 管理番号: #0022
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-28
- 関連: #0023（App Store 用スクリーンショット。作る途中でこの問題に気づいた）

## 概要

スマホでは、盤面と十字ボタンの間に設定のボタンが3段あり、十字ボタンの下半分が画面の外にはみ出していた（十字ボタンで遊ぶにはスクロールが必要だった）。十字ボタンを盤面のすぐ下に移し、設定のボタンをその下に回した。また、iPad や PC の大きい画面では盤面が 520px で止まり小さく見えていたので、上限を 760px に上げた。

## 対象ファイル

- `index.html` … 十字ボタン（`.dpad`）と設定のボタン（`.controls`）の並び順、`layout` の盤面の上限

## 変更内容

- 並び順を「盤面 → 設定のボタン → 十字ボタン」から「盤面 → 十字ボタン → 設定のボタン」に変えた
  - 十字ボタンはタッチ操作の端末（スマホ・タブレット）だけに出るので、PC の見た目は変わらない
  - スマホでは、動かす操作が盤面のすぐ下に全部見える。はみ出すのは設定のボタンの下の段（使う回数が少ないもの）になる
- 盤面の大きさの上限を 520px → 760px にした。画面の幅と高さに合わせて決める計算はこれまでどおりで、上限だけを上げた
  - iPad 13インチ（縦）: 520px → 760px
  - PC: 画面の高さに余裕があれば、520px より大きくなる

## 確認結果

- App Store 用スクリーンショットの作成（#0023）で、端末の大きさとタッチ操作の設定で表示して確かめた

| 端末 | 変更前 | 変更後 |
|---|---|---|
| iPhone 6.9インチ | 十字ボタンの ▼ が画面の外に切れる | 十字ボタン全体が盤面の下に見え、設定のボタンは2段目まで見える |
| iPhone 5.5インチ | 十字ボタンの ▼ が見えない | 十字ボタン全体と、設定のボタンの2段目まで見える |
| iPad 13インチ | 盤面 520px（画面の半分ほど） | 盤面 760px |

- PC（ブラウザの画面）では、十字ボタンが出ず、並びも変わらないことを確認
- 自動テスト（`node tools/test.mjs`）22件すべて OK
